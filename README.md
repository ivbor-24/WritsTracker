# WritsTracker

**Трекер дейликов Craftsman's Writs для WoW: Forever** — качай репутацию
Durotar Supply & Logistics (Орда) / Azeroth Commerce Authority (Альянс)
без лишней беготни и математики.

150 writs всех пяти профессий, точки сдачи на карте, реагенты с подсчётом
в сумках, экономика «сколько золота стоит 1 репутация» и статусы дейликов —
в одном окне.

## Зачем это нужно

Craftsman's Writ — это предмет-заказ, который дропается в мире или покупается
на аукционе. Он начинает **ежедневный квест**: принеси NPC запрошенный
предмет — получи репутацию и Coin Pouch с золотом. Writs бывают трёх тиров:

| Тир | Уровень персонажа | Репутация | Пример |
|---|---|---|---|
| Journeyman | 10+ | +75 | Big Bronze Bomb |
| Expert | 20+ | +125 | Goblin Land Mine |
| Artisan | 35+ | +200 | Field Repair Bot 74A |

Проблемы, которые решает аддон:

- **«Какой writ выгоднее?»** — посчитает цену реагентов / готового предмета /
  самого writ и покажет, сколько меди стоит 1 репутация каждым путём.
- **«Где это сдавать?»** — точки сдачи прямо на карте и миникарте, waypoint
  одним кликом.
- **«Что мне вообще доступно?»** — фильтр по вашим профессиям и уровню,
  статус «знаю рецепт / не знаю», «хватает реагентов / не хватает».
- **«Я уже сдал это сегодня?»** — таймер до серверного ресета на каждом writ.
- **«Что докупить?»** — одна кнопка собирает недостающие реагенты в список
  покупок Auctionator.

## Сценарии использования

### 1. Утренняя рутина: что сдать сегодня

Открываешь `/wt`. Фильтр «Мои профессии» уже стоит по умолчанию — видишь
только writs своих профессий. Ставишь статус **«Готовы»** — остаются те,
где рецепт изучен и реагентов хватает. Сортируешь **«Цена/реп»** — сверху
самые дешёвые по золоту за репутацию. Кликаешь по строке → **Waypoint** →
бежишь сдавать. Сдал — строка помечается «сдан, снова через Nч» и уходит
из фильтра «Готовы».

### 2. Планирование прокачки репутации

Сортировка **«Репутация»** — сверху Artisan (+200). Смотришь, каких writs
не хватает до следующего ранга репутации. Фильтр «Не знаю» покажет рецепты,
которые стоит выучить; у каждого виден порог скилла и ваш текущий ранг
профессии — сразу понятно, докачаться ли до него.

### 3. Закупка реагентов на аукционе

Отфильтровал writs, которые хочешь делать (например, «Знаю» + «Мой уровень»).
Жмёшь **«Купить (AH)»** — аддон суммирует недостающие реагенты всех writs
списка и создаёт готовый shopping list в Auctionator. Открываешь аукцион,
запускаешь список — покупаешь всё за один проход.

### 4. Нашёл writ в сумке — что с ним делать

Наводишь на writ-предмет в сумке (или на ссылку в чате/аукционе) — тултип
сразу показывает: сколько реп даёт, какой предмет нужен, хватает ли
реагентов, где сдавать, сдан ли сегодня и экономику. Окно аддона открывать
не нужно.

### 5. Фарм writs на продажу

Сортировка «Цена/реп» + тултипы показывают вердикт **«выгоднее продать
writ»** — когда цена writ на аукционе выше, чем выгода от сдачи. Такие
writs лучше продать, а репутацию качать другими.

### 6. Незнакомая зона — где тут сдавать

Пины точек сдачи видны на world map и миникарте (иконка writ, рамка цвета
тира). Вошёл в зону, где есть готовые writs — аддон сам напишет в чат:
«3 готовых writs в зоне — можно сдать». Навёл на пин — тултип с NPC,
координатами и статусом.

### 7. Writ с неизвестной точкой сдачи

10 Artisan-writs пока без известной точки. Если сдашь такой — аддон
**сам запомнит** NPC и координаты, пин появится сразу. `/wt export` выведет
выученное в чат — пришли автору (issue в репо), точка попадёт в следующую
версию для всех.

## Окно аддона

```
┌──────────────────────────────────────────────────────────────────┐
│  Craftsman's Writs — дейлики                                  [X] │
│  Профессия  Рецепт  Зона по уровню  Тир  Статус  Сортировка      │
│  [v] Скрыть Moonglade  [v] Скрыть сданные  [v] Пины   Поиск...  │
│  [Waypoint] [Купить (AH)] [Обновить]                             │
│ ─────────────────────────────────────────────────────────────── │
│  [icon] Heavy Quiver (Кожевник)                            [writ]│
│         Stonetalon Mountains • Ziz Fizziks • Journeyman          │
│         [знаю] скилл 125/224 • 1с 27м/реп                        │
│         0/8 Heavy Leather  0/2 Fine Thread   ← клик = поиск в AH │
│ ─────────────────────────────────────────────────────────────── │
│  ...                                                             │
│  Показано 12 из 150    Клик по ингредиенту — аукцион • СКМ — wp  │
└──────────────────────────────────────────────────────────────────┘
```

**Строка writ:**
- Иконка предмета-заказа, название, профессия.
- Зона и NPC сдачи, тир, статусы: `[знаю]`/`[не знаю]`, `[в журнале]`,
  `[сдан, через Nч]`, скилл профессии vs порог рецепта, цена за 1 реп.
- Реагенты крафта: `имеется/нужно Название` — зелёный если хватает,
  красный если нет. **Каждый реагент — кнопка**: клик ищет именно его
  в аукционе, наведение показывает тултип предмета.
- Иконка writ справа: Shift+клик — поиск самого writ на аукционе.

**Управление:**
| Действие | Что делает |
|---|---|
| Клик по ингредиенту | Поиск этого реагента в аукционе (Auctionator) |
| Shift+клик по строке | Ссылка на предмет-заказ в аукцион/чат |
| ПКМ по строке | Прямой поиск предмета в Auctionator |
| СКМ по строке | Waypoint на точку сдачи |
| ЛКМ по строке | Выбрать writ (для кнопки Waypoint) |
| Клик по иконке writ | Shift — поиск writ на аукционе |

**Фильтры:**
- **Профессия** — «Мои профессии» (по умолчанию), все, или конкретная.
- **Рецепт** — все / знаю / не знаю.
- **Зона по уровню** — все / мой уровень / не мой уровень (writ требует
  уровень 10/20/35 по тирам).
- **Тир** — Journeyman / Expert / Artisan.
- **Статус** — все / готовы (знаю + хватает) / не хватает / сданы.
- **Скрыть Moonglade** — зона друидов, остальным туда долго.
- **Скрыть сданные сегодня** — убрать из списка то, что уже сдано.
- **Пины на карте** — вкл/выкл пины точек сдачи.
- **Поиск** — по имени предмета, зоне или NPC.

**Сортировка:** профессия, зона, скилл, имя, цена/реп, репутация, уровень.

## Экономика (нужен Auctionator)

Аддон считает **три пути** получения предмета-заказа для каждого writ:

1. **Скрафтить** — сумма цен реагентов на аукционе (если рецепт изучен).
2. **Купить готовое** — цена предмета-заказа на аукционе.
3. **Купить writ** — цена самого writ-предмета (если его нет в сумках).

Лучший путь → полная стоимость → минус награда (Coin Pouch тира, среднее
из ваших открытий) → **медь за 1 репутации**. Цветной рейтинг:
- 🟢 дёшево (по умолчанию ≤ 5с за реп)
- 🟡 средне (≤ 15с за реп)
- 🔴 дорого

Вердикт **«выгоднее продать writ»** — когда цена writ выше выгоды от сдачи.
Возраст цен показывается («3 дн.» — скан устарел). Пороги рейтинга
настраиваются в SavedVariables (`cheapCPR`, `expensiveCPR`).

Без Auctionator экономика не считается, остальное работает.

## Пины на карте

140 из 150 точек сдачи известны (данные Wowhead + QuestieDB). Пины:
- на **world map** и **миникарте**;
- иконка writ-предмета, рамка цвета тира (синий/зелёный/фиолетовый);
- тултип: NPC, зона, координаты, статус (сдан / в журнале / знаю рецепт);
- следуют фильтрам окна; сданные сегодня скрыты;
- 10 неизвестных Artisan-точек аддон **выучит сам** при первой сдаче.

Библиотека HereBeDragons-Pins (с патчем для клиентов без MapCanvas) +
classic-фолбэк. Работает и на старой карте, и на новой.

---

## Дейли-статусы

- **[сдан, через 5ч 12м]** — таймер до серверного ресета
  (`GetSecondsUntilDailyReset`), а не просто флаг «сегодня».
- **[в журнале]** — квест принят и висит в логе.
- Статус пишется при сдаче (`QUEST_TURNED_IN`) в per-character SavedVariables
  и переживает релог. Если клиентский API врёт — собственный лок страхует.

## Кнопка у миникарты и Bazooka

- **Кнопка у миникарты**: иконка writ + счётчик «сдано/доступно» writs
  максимального доступного тира по вашим профессиям (Artisan с 35 ур.,
  Expert с 20, иначе Journeyman). Перетаскивается по кругу миникарты.
  ЛКМ — окно, ПКМ — пересчёт. `/wt minimap` — вкл/выкл.
- **Брокер для Bazooka** (и любого LDB-дисплея): тот же счётчик в панели,
  тултип с разбивкой по тирам. Появляется автоматически.

## Установка

1. Скачайте `WritsTracker-x.y.z.zip` из [последнего релиза](https://github.com/ivbor-24/WritsTracker/releases/latest).
2. Распакуйте в `Interface/AddOns/` клиента WoW: Forever
   (должна получиться папка `Interface/AddOns/WritsTracker/`).
3. Включите аддон в списке аддонов на экране выбора персонажа.
4. В игре: `/wt`.

**Опциональные зависимости** (всё работает и без них, но с ними лучше):
- [Auctionator](https://www.curseforge.com/wow/addons/auctionator) — экономика,
  shopping list, поиск по клику.
- [TomTom](https://www.curseforge.com/wow/addons/tomtom) — waypoint со стрелкой
  (без него — встроенный маркер Blizzard).
- [Bazooka](https://www.curseforge.com/wow/addons/bazooka) — панель брокеров.

## Данные и ограничения

- **150 writs** всех 5 профессий: гайд Wowhead Forever (Serenal) +
  Wowhead search/XML + QuestieDB (NPC questEnds/spawns).
- **140/150 точек сдачи** известны. 10 Artisan-writs пока без точки —
  аддон выучит при первой сдаче, `/wt export` чтобы поделиться с автором.
- Экономика требует **скана Auctionator** — без цен в его базе будет
  «нет цен». Просканируйте аукцион хотя бы раз.
- Награда Coin Pouch считается по **вашим открытиям** (среднее по тиру);
  до первого открытия — справочные значения гайда.
- `WritsDB.lua` сгенерирован — правки данных через генератор, не вручную.

## Производительность

Аддон оптимизирован под слабый CPU:
- кэш цен и счётчиков предметов на один пересчёт;
- ленивый рендер — создаются только видимые строки списка;
- пины пересоздаются только при смене фильтров;
- троттлинг событий сумок/квестов (пачки коалесцируются в один пересчёт).

Открытие окна и прокрутка не должны фризить.
