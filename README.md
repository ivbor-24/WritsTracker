# WritsTracker — Craftsman's Writ dailies для WoW: Forever

Аддон-трекер дейликов **Craftsman's Writs** (репутация Durotar Supply & Logistics /
Azeroth Commerce Authority) для WoW: Forever (interface 16001). 150 writs всех
5 профессий с точками сдачи на карте, экономикой и статусами.

## Возможности

- **Каталог 150 writs**: предмет-заказ, NPC и зона сдачи, тир (Journeyman/Expert/Artisan).
- **Знаю / не знаю рецепт** — детект через `IsPlayerSpell` (сверено с Mastercraft, точное совпадение).
- **Реагенты крафта** с количеством в сумках и банке (зелёный = хватает).
- **Экономика через Auctionator**: три пути получения предмета — скрафтить /
  купить готовое / купить writ. Стоимость минус награда (Coin Pouch) →
  **медь за 1 репутации** с цветным рейтингом. Вердикт «выгоднее продать writ».
- **Пины точек сдачи** на world map + миникарте (140/150 с координатами),
  иконка writ, рамка цвета тира, тултип с NPC/координатами/статусом.
- **Тултипы writ-предметов** в сумке/чате/аукционе: реп, реагенты, точка сдачи,
  дейли-статус, экономика — без открытия окна.
- **Дейли-лок с таймером** до серверного ресета («сдан, снова через 5ч 12м»).
- **Самообучение точек сдачи**: сдаёшь writ с неизвестной точкой — аддон
  запоминает NPC и координаты, пин появляется сразу. `/wt export` — поделиться.
- **Кнопка у миникарты** + **брокер для Bazooka**: «сдано/доступно writs
  максимального доступного тира по моим профессиям».
- **Waypoint** (TomTom или Blizzard supertrack), **shopping list** недостающих
  реагентов в Auctionator одной кнопкой.
- Фильтры: профессия (авто = мои), знаю/не знаю, зона по уровню, тир, статус
  (готовы/не хватает/сданы), скрыть Moonglade (друиды), текстовый поиск.
- Сортировка: профессия / зона / скилл / имя / цена-за-реп / репутация.
- **Shift-клик** — предмет в поиск аукциона, **СКМ** — waypoint.
- Зональный алерт: вошёл в зону с готовыми writs → сообщение в чат.
- Dual-prof writs (Goblin Rocket Fuel, Gordok Ogre Suit) — вариант под вашу профессию.

## Установка

1. Скачайте последний релиз (zip) или клонируйте репозиторий.
2. Папку `WritsTracker` положите в `Interface/AddOns/` клиента WoW: Forever.
3. Включите аддон в списке аддонов на экране выбора персонажа.

Опционально: **Auctionator** (экономика, shopping list, shift-click поиск),
**TomTom** (waypoint), **Bazooka** (брокер в панели).

## Команды

- `/wt` (или `/writs`) — окно.
- `/wt scan` — пересчитать, сводка в чат.
- `/wt pins` — пины вкл/выкл.
- `/wt minimap` — кнопка у миникарты вкл/выкл.
- `/wt shop` — список покупок в Auctionator.
- `/wt export` — выученные точки сдачи в чат.
- `/wt selftest` — диагностика (результат в SavedVariables).
- `/wt debug` — профессии, API, статус пинов.

Если стоит xeR's Forever Writs & Waylaid — используйте `/wt` (у него тоже `/writs`).

## Данные

150 writs: гайд Wowhead Forever (Serenal) + Wowhead search/XML + QuestieDB
(NPC questEnds/spawns). Точки сдачи: 140/150 известны; 10 Artisan-writs пока
без точки — аддон выучит её при первой сдаче (`/wt export` чтобы поделиться).

`WritsDB.lua` сгенерирован — правки данных через генератор, не вручную.
